# Business Card Generator

Generate professional business cards using AI (NANO-BANANA / Gemini). Front + back in one image, style-locked color palette.

## Prerequisites

```bash
pip3 install requests
```

## Input

| Field | Required | Description | Example |
|-------|----------|-------------|---------|
| **person_name** | Yes | Full name | "Zhang San" |
| **title_position** | Yes | Job title | "Product Director" |
| **company_name** | Yes | Company/organization | "ByteWave" |
| **phone** | No | Phone number | "+86 138-xxxx-xxxx" |
| **email** | No | Email address | "zhang@bytewave.com" |
| **website** | No | Website URL | "bytewave.com" |
| **address** | No | Physical address | "Beijing, China" |
| **logo_description** | No | Logo visual description (text) | "Blue wave icon with letter B" |
| **subtitle** | No | Company tagline (for back) | "Ride the Wave of Innovation" |
| **style_preset** | No | Visual style (default: minimalist) | See table below |
| **reference_image_url** | No | Reference card image path | "/path/to/ref.jpg" |

Each style auto-locks its color palette — no need to choose colors separately.

## Workflow

### Phase 0 — Collect Input

Gather card information from the user:

1. Extract any info the user already provided (name, title, company, contact details)
2. Ask only for missing required fields (person_name, title_position, company_name)
3. Optional fields: include if user mentions them, don't ask if not provided
4. Style: let user pick from presets, or default to minimalist

If user gives natural language (e.g., "make me a card, I'm Zhang San, Product Director at ByteWave"), extract all info and only ask for what's missing.

If user uploads a reference business card image, record the absolute local path as `reference_image_url`.

### Phase 1 — Confirm

Show the card spec summary:

```
Name: Zhang San
Title: Product Director
Company: ByteWave
Contact: zhang@bytewave.com
Style: tech
Colors: #1A1A2E / #E0E0E0 / #00E5FF
Size: US Standard (2100x1200)
Output: Front + back in one image
```

Ask user to confirm or adjust.

### Phase 2 — Generate

Write card spec to JSON, then run:

```bash
cat > /tmp/card_spec.json << 'EOF'
{
  "person_name": "Zhang San",
  "title_position": "Product Director",
  "company_name": "ByteWave",
  "email": "zhang@bytewave.com",
  "style_preset": "tech",
  "generate_back": true
}
EOF

python3 scripts/generate_card.py --from-json /tmp/card_spec.json --generate-back -v
```

Only include fields the user actually provided. The script auto-fills:
- Color palette from the style preset
- Size: us_standard (2100x1200)
- Language: auto-detect from name
- Generates front + back side by side in one image (1 API call)

### Phase 3 — Report

Show the generated card image. Output: `output/cards/<name-slug>/card_combined.png`
(Front + back side by side in one image, generated by AI in a single call)

If user wants changes:
- Different style → update `style_preset`, re-run
- Fix text → update fields, re-run
- Remove back side → remove `generate_back`, re-run (generates front only)

## CLI Reference

| Flag | Description |
|------|-------------|
| `--from-json` | Path to card spec JSON |
| `--person-name` | Person name (alternative to JSON) |
| `--style` | Style preset (default: minimalist) |
| `--size` | Size preset or WxH (default: us_standard) |
| `--language` | en / zh / bilingual (default: auto-detect) |
| `--reference-image` | Reference image path for style matching |
| `--generate-back` | Include back side in the image |
| `--dry-run` | Preview prompt without API call |
| `-v` | Verbose logging |

## Error Handling

| Problem | Fix |
|---------|-----|
| API submit failed | Retry |
| Task FAILED | Simplify prompt, remove conflicting instructions |
| Task TIMEOUT | Retry |
| Chinese text garbled | Reduce to 4-6 chars, use sans-serif, avoid traditional characters |
| Small text unreadable | Reduce contact fields |

## Known Limitations

- Front + back in one image, one API call (~45 seconds)
- Chinese text rendering may have errors — verify output
- Keep contact info to 3-5 fields for best visual results
- Output is PNG for text sharpness
